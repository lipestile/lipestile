### ⚡ Core Architecture &amp; Engineering

Graduando em **Análise e Desenvolvimento de Sistemas (IESB)** e **Engenharia de Software (Anhanguera)**.

> *A abordagem: arquitetura sólida, contratos de API estritos, pipelines automatizados e código que sobrevive ao tempo — integrando processos corporativos de ponta a ponta.*

- 🔭 **Current Arc**: Arquitetura de ERPs de Alta Disponibilidade (**TOTVS Protheus &amp; Fluig**) com orquestração de processos analíticos e preditivos em **Python**.
- 🌱 **Stack Expansion**: **TL++ Orientado a Objetos**, esteiras de aprovação dinâmicas no Fluig BPMN, consumo de APIs RESTful e interfaces ágeis com **PO-UI &amp; Modern Web**.
- ⚡ **The Code**: *"Do or do not, there is no try."* — Priorizo commits atômicos, resiliência em transações financeiras críticas e queries SQL otimizadas.
- 🛡️ **DevOps &amp; CI/CD**: Esteiras automatizadas de integração e entrega contínua com GitHub Actions.
